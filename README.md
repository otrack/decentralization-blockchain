# Blockchain and Decentralization

(🚧 Work in progress)

This course is about the theory and practice of blockchain and decentralized systems.
In particular, the following topics are covered:
- Smart contracts
- Decentralized finance (DeFi) and organizations (DOA)
- Mempool and data dissemination
- Consensus and state-machine replication (Paxos)
- Byzantine Fault-tolerance (PBFT)
- Conflict-free replicated data types (CRDTs)
- Distributed ledgers (Proof-of-X)
- Privacy in blockchain
- Asset transfer and cross-chain transactions (ABCI)
